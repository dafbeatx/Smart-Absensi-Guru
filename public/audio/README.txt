=====================================================
FOLDER AUDIO / SOUND EFFECTS - SMART ABSENSI GURU
=====================================================

Simpan file audio (.mp3 / .wav) Anda di folder ini:

1. success.mp3  -> Suara saat aksi BERHASIL (Scan QR sukses, simpan data, login, dll)
2. error.mp3    -> Suara saat aksi GAGAL (Scan QR gagal, PIN salah, error koneksi, dll)
3. beep.mp3     -> Suara beep deteksi QR Code

Sistem telah dilengkapi dengan AudioService otomatis di:
src/services/audio.service.ts
